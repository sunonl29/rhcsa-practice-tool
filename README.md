RHCSA Command Practice Tool
Version 1.0

INSTALLATION
------------
1. Save the binary somewhere on your PATH, e.g.:
     mv rhcsa-practice-1.0-linux-x64 ~/bin/rhcsa-practice
     chmod +x ~/bin/rhcsa-practice

2. Run it:
     rhcsa-practice

FIRST LAUNCH
------------
You will be asked for a license key. You should have received a .key
file by email. Either:

  Option A: Open the .key file, copy its full contents, paste into the
            text box, and click "Save & Verify".

  Option B: Type the path to your .key file (e.g. ~/Downloads/My.key)
            and click "Load from File".

Once verified, you won't be asked again.

USAGE
-----
  1  Learn Mode         Browse commands with syntax and examples
  2  Drill Mode         Practice commands with 3-level hints
  3  Timed Challenge    Race against the clock
  4  Progress Dashboard See your accuracy per domain
  5  Settings           Timers, hints, difficulty
  Q  Quit

DATA
----
Progress, settings, and your license are stored in:
  ~/.config/rhcsa-practice/

Remove that folder to reset everything.
