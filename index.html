Getting Started

Installation

  1. Save the binary somewhere on your PATH: 
    mv rhcsa-practice-1.0-linux-x64 ~/bin/rhcsa-practice
chmod +x ~/bin/rhcsa-practice
  2. Run it: 
    rhcsa-practice

First Launch

You'll be asked for a license key. You should have received a .key file by email. Either:

  • Option A: Open the .key file, copy its full contents, paste into the text box, and click Save & Verify.
  • Option B: Type the path to your .key file (e.g. ~/Downloads/My.key) and click Load from File.

Once verified, you won't be asked again.
